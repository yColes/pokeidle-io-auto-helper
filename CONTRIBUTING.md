# Contribuindo

Obrigado pelo interesse em melhorar o projeto.

## Relatando bugs

Abra uma issue com o máximo de contexto possível: versão da extensão, navegador, passos para reproduzir, resultado esperado e resultado observado. Screenshots ajudam bastante quando o problema envolve alterações na interface do jogo.

## Pull requests

1. Crie um fork do repositório.
2. Crie uma branch curta e descritiva.
3. Faça alterações focadas em um problema ou recurso.
4. Teste a extensão carregando-a como extensão sem compactação.
5. Abra o pull request explicando o que mudou e como foi validado.

Evite incluir credenciais, dados pessoais, arquivos de sessão ou qualquer segredo no código e nos relatórios.
