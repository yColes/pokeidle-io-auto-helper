# Changelog

## 1.3.0

- Detector de proximidade refeito para identificar as linhas de Pokémon, não o cabeçalho.
- Clique enviado ao elemento dentro do primeiro card visível e não ao painel.
- Diagnóstico de captura copiável pelo popup.
- HUD informa número de linhas e estado do clique.
- Cooldown de 2,05 segundos e cache de baixo consumo mantidos.

## 1.2.0 — Correção da lista de captura

- Reconhece somente uma linha de Pokémon, como `Abra Nv10`.
- Impede cliques no painel inteiro `PROXIMIDADE PARA CAPTURAR`.
- Conserva o cooldown de 2,05 segundos e o modo de baixo consumo.
- Evita afirmar estoque zero quando a leitura de Pokébolas é inconclusiva.

## 1.1.0

- Auto captura corrigida para clicar diretamente nos retângulos do painel **PROXIMIDADE PARA CAPTURAR**.
- Cooldown padrão ajustado para aproximadamente 2,05 segundos.
- Cache do painel para reduzir processamento.
- Mantidos histórico, HUD, alertas e controle rápido.

## 1.0.0

- Primeira versão específica para PokeIdle.io.
